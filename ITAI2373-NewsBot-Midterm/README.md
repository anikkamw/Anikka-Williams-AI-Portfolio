# NewsBot Intelligence System (ITAI 2373 Midterm)

An end-to-end Natural Language Processing (NLP) pipeline that processes, categorizes, and extracts structured insights from news articles using the BBC News dataset.

## System Architecture & Pipeline
This project integrates core NLP techniques across 8 modules:
- **Module 1:** Real-World Application & Business Case
- **Module 2:** Text Preprocessing & Cleaning (Tokenization, Lemmatization, Stop Words)
- **Module 3:** TF-IDF Feature Extraction & Keyword Analysis
- **Module 4:** Part-of-Speech (POS) Pattern Analysis
- **Module 5:** Dependency Parsing & Syntactic Structure
- **Module 6:** Sentiment & Emotional Tone Analysis
- **Module 7:** Multi-Class Text Classification (Naive Bayes, Logistic Regression, Random Forest)
- **Module 8:** Named Entity Recognition (NER for PERSON, ORG, GPE, DATE, MONEY)
